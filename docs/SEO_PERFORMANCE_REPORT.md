## What changed

### Performance (PHP / MySQL)
- **Homepage/top N+1 fixed**: `trending_score()` (→ `click_count()` → `COUNT(*)`) ran inside a `usort` comparator, i.e. ~2·n·log n queries. Scores are now computed once per tool, and click/vote counts are loaded with **one grouped query each** per request (`all_click_counts()`, `all_vote_counts()`), invalidated after writes.
- `site_cfg()` (called for every tool card via `tool_url()`) is cached per request; table-existence checks share one `SHOW TABLES`; `load_tools()`, JSON reads and compare points are cached per request; compare points are fetched in one query instead of five.
- Category pages are paginated (48/page, `rel=prev/next`) instead of rendering 432 cards.

### Front-end
- Logo 112 KB PNG → 2–4 KB WebP (`srcset` 1x/2x, explicit width/height); favicon 203 KB → 1.6 KB (plus 48/180/192/512 icons + web manifest).
- CSS/JS cache-busted (`?v=filemtime`), JS `defer` + absolute paths (was broken under `/compare/`), footer inline CSS moved to the stylesheet.
- All tool logos: `alt`, `width/height`, `loading="lazy"`, `decoding="async"`; preconnect to the favicon CDN.
- `.htaccess`: gzip, 30-day static caching, `nosniff`, referrer policy.

### Technical SEO
- New `seo.php`: titles (brand once, ≤70 chars), descriptions (≤158 chars, cleaned), canonical builder (fixed `https://aihubpedia.com` host, whitelisted params per page, sorted compare pairs), robots logic, JSON-LD `@graph` builder, breadcrumbs.
- Every page now has a unique title + description (560/560 sitemap URLs unique); ~25 pages previously shared the default title.
- Canonicals no longer echo arbitrary query strings (`?utm_…`, `?q=`); search/filter/param URLs and all errors are `noindex, follow`; utility/demo/placeholder pages (login, bookmarks, admin, `ai-*` previews, `/extensions/*`) are `noindex`.
- **Real 404s** for unknown tools, categories, posts, comparison pairs, category pages out of range, and unknown URLs (`ErrorDocument 404`; previously soft-404s / Apache default page). Branded 404 page with search.
- **Sitemap rebuilt**: `sitemap.php` fatal error fixed; it listed non-existent `/tools/{slug}` URLs. Now 560 valid canonical URLs (tools, categories + pages, use cases, posts, comparisons, static pages) with `lastmod`; `/sitemap.xml` rewrites to it; static copy regenerated by `php scripts/build-seo-files.php`.
- **robots.txt**: absolute `Sitemap:` URL (was relative/invalid), blocks action endpoints/install scripts/private folders, names Googlebot, Bingbot, OAI-SearchBot, ChatGPT-User, GPTBot, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended explicitly.
- **AI discoverability**: `/llms.txt` (llmstxt.org format) with categories, curated tools and comparisons, plus guidance to cite pages and verify pricing.
- Leading newline before `<?php` removed from 20 files (incl. `helpers.php`, `redirect.php`, `subscribe.php`) — it broke the sitemap XML and `Location:` redirects when output buffering is off.
- `index.php` → `/` 301, `www` → apex 301, legacy `search.php` (old SearchAction target that 404'd) → 301 to `/?q=`.

### Structured data (JSON-LD, validated in tests)
- Site-wide `Organization` + `WebSite` with a working `SearchAction`.
- Tool: `SoftwareApplication` (category mapping, official URL, logo), `Offer` only when the listing states a free tier, `aggregateRating` **only** when real visitor ratings exist; `BreadcrumbList`.
- Category/categories/top/leaderboard/use-case/comparisons: `CollectionPage` + `ItemList`; compare pairs: `WebPage` about two `SoftwareApplication`s; posts: `BlogPosting` with dates; blog: `Blog`.

### Content accuracy (misleading claims)
- 499 of 509 tools carry the same bulk-generated features/pros ("Fast setup and onboarding", "Saves time"…). Tool pages now say these are general notes not verified for that product, relabel the sections, and list curated tools first in alternatives/categories.
- Compare page: "Best overall value" / "Overall edge" → "More complete profile"; "Verified compare data" → "Source-backed profile"; a note explains scores measure data coverage, not quality. Removed the developer note shown to visitors.
- Homepage: "Trending … based on clicks" now discloses the editor-pick list; sponsored-placement copy no longer implies guaranteed traffic. `/comparisons.php` no longer shows internal instructions.
- `ai-benchmarks.php`, `ai-trend-radar.php` and `/extensions/*` placeholder pages are labelled as illustrative and `noindex`.
- Fixed "a automation AI tool" grammar in generated descriptions.

### Internal linking & mobile
- Breadcrumbs (visible + schema) on tool, category, compare, post, blog, top pages.
- Tool names link to tool pages everywhere; categories link from tool cards/meta; "X vs Y" links from every alternative; category and popular-comparison link blocks on home, compare, categories and category pages; footer adds comparisons/disclaimer, absolute URLs.
- Outbound/action links get `rel="nofollow"` (redirect, bookmark, demo login, half-filled compare).
- `<main>` now wraps page content (was an empty element), skip link, labelled form fields, 16px inputs on mobile.
- Mobile header: was sticky and ~400px tall (≈20% of the viewport) with 19px tap targets → compact, non-sticky, 40px targets.
