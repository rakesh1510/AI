# Premium 3D UI v2 — six redesigned pages

Branch `feat/aihubpedia-premium-3d-ui-v2` (on top of `feat/aihubpedia-premium-3d-ui`). Frontend/presentation only. Local validation only (PHP built-in server, JSON catalogue, no database). Nothing deployed; AI Universe remains hidden.

## Design approach
The six supplied images were used as **style references** (dark lit hero, marketplace tiles, VS comparison, editorial layout, 3D agency landing, pricing cards). No reference artwork, logos or brand names were copied; all illustrations are original inline SVG/CSS.
- **Stage sections**: an always-dark, violet/blue/cyan lit band (`.stage`) used for heroes and the business/pricing bands, so the premium look works in both themes; content areas follow the light/dark theme.
- **Illustrations** (`art.php`): glossy ring/orb hero art, cube-robot agent on a lit platform, workflow strip, category-tinted editorial thumbnails, ad-placement previews. Pure SVG, no network, no scripts.
- **Logo tiles**: a monogram tile with the logo over it; if a logo cannot load the monogram stays (small JS in `app.js`). Logos are never required for layout.
- **Depth**: layered glass cards, soft shadows, glossy tilted icon tiles, restrained hover lift; reduced-motion and `hover:none` disable movement.
