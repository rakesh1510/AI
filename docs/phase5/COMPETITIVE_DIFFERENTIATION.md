# Competitive differentiation (Phase 5)

**Method and limits.** This phase did not re-access any competitor. The Phase 4 benchmark (`docs/phase4/COMPETITOR_ANALYSIS.md`) could only use public search summaries because the competitor site was unreachable from the sandbox, and that remains true: every competitor statement is a claim seen in search results and is *not verified*. Nothing here asserts that AIHubpedia is better, larger or more trusted. The aim is utility that can be demonstrated on this site.

## Where AIHubpedia cannot compete (do not pretend)
* **Breadth.** 509 listings against a competitor's claimed 2,500+. Chasing breadth would dilute the evidence advantage.
* **Audience channels.** No launched newsletter, no measured audience, no social following. Sponsorship cannot be sold on audience.
* **Editorial capacity.** 0 of 509 profiles are verified by a person. This is the binding constraint, not code.

## Where it can be credibly different, and what Phase 5 added
| Differentiator | Why it matters to a visitor | Phase 5 evidence |
|---|---|---|
| **Inspectable evidence per fact** | A buyer can see which price, which source, which date, and when it expires | Evidence ledger on tool pages and comparison rows (documented / unknown / conflicting / stale / verified) |
| **Honest unknowns** | "We don't know" is more useful than a template pro/con | Template text removed from search and comparisons; unreviewed tools say "unknown" |
| **Recommendations that cannot be bought** | Decision support is only useful if it is independent | New tests mutate sponsorship, affiliate and click data and assert wizard, problem pages and comparison pairs are unchanged |
| **Better task search** | People type jobs, not product names | 28-query fixture: precision@5 0.593 to 0.679, success@3 0.893 to 0.964, MRR 0.806 to 0.912 |
| **A verification workflow whose label is not for sale** | "Verified" means a named person checked | Checklist-gated log; no code path verifies; label cannot be purchased (packages do not touch evidence) |
| **International readiness without machine-translation spam** | Trust in a new market needs reviewed text | Locale architecture with reviewer-gated publishing and duplicate/canonical validation |

## What this is not
A claim of ranking, traffic or revenue advantage. Those are outcomes to measure after a separately approved launch (see METRICS_AND_EXPERIMENTS.md).
