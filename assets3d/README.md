# AIHubpedia studio renders (`assets3d/`)

Original 3D artwork for the site, rendered offline with **Blender 5.3 (bpy) + Cycles** (path tracing, OpenImageDenoise denoiser). Nothing here runs on the web server or in the browser.

## Reproduce
```bash
python3 -m venv /tmp/bpyenv && /tmp/bpyenv/bin/pip install bpy pillow
./assets3d/build_assets.sh            # every scene + the four article covers -> assets/art/*.webp
./assets3d/build_assets.sh podium     # one scene
```
`lib.py` holds the procedural materials (chrome, glass, glossy coat, iridescent violet/blue/cyan/magenta ramp driven by Layer Weight) and the studio lighting (five emissive softboxes for reflections). `scenes/*.py` build one scene each. `convert.py` crops to the alpha bounding box and writes `name.webp` (<=1100 px wide) and `name-sm.webp` (560 px, served to phones through `srcset`).

## Provenance and licensing
- Every mesh, material, curve and light is generated by the scripts in this folder. **No third-party models, HDRIs, textures, images, fonts or presets are used**, and nothing is traced from or copied from the reference designs.
- The only typeface in the renders is Blender's bundled default font (numerals "1", "2", "3", "VS", "?"), distributed with Blender under its licence; the glyph shapes in the rendered pixels are not an embedded font file.
- The rendered WebP files are original works of the site owner. Blender output is not encumbered by Blender's GPL licence.
- Site typefaces (separate from the renders): Space Grotesk and Inter, SIL OFL 1.1, hosted locally in `assets/fonts/` with their licence files.

## Budget
Every image is lazy-loaded except the hero artwork (`fetchpriority=high`), has intrinsic width/height (no layout shift), is `aria-hidden` decoration, and is served as WebP with alpha. Sizes are listed in `docs/redesign/v3/REPORT.md`.
