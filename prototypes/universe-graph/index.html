    Keyboard and touch help
    • Graph focused: Arrow keys pan, + / - zoom, 0 fit all, Esc clear selection.
    • Enter selects the node nearest the centre (or zooms into the nearest cluster); then Enter again opens its details.
    • N / Shift+N next / previous node by distance from the centre; ] / [ next / previous related node; B back to the previous selection.
    • Buttons on the graph do the same without keys. The Table view lists the same nodes and keeps the selection.
    • Touch: drag to pan, pinch to zoom, tap a node or cluster.
    Legend (relationship types and node types)

    Arrow keys pan, plus and minus zoom, zero fits all, Enter selects the node nearest the centre, N and Shift N cycle nodes, right and left square brackets cycle related nodes, B goes back, Escape clears the selection. The Table view is an equivalent list.
